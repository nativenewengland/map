# Independent source-link checks

Five physical clicks on sources in the regional evidence panel opened new tabs in Edge. The dates below are Gregorian. After the network sandbox prevented the first pass, the browser repeated the clicks with external network access. The charter PDF, Connecticut register and Mashpee timeline loaded with HTTP 200. JSTOR returned an HTTP 200 client-challenge page. The Massachusetts Secretary of the Commonwealth returned HTTP 403 to headless Edge. Independent web retrieval opened the JSTOR catalog record and the Massachusetts table, including the Amesbury entry. None of these five requests returned HTTP 404.

The June 12, 1665 English-calendar instrument joined New York, New Harlem and the Crown’s other subjects living on Manhattan under municipal officers. June 22 is its Gregorian equivalent. The island shoreline locates the jurisdiction. The charter governs people and judicial administration. It supplies no survey of occupation or title to individual parcels. A separate publication of the instrument reproduces the same terms on page 390. [Papers relating to the City of New York](https://www.e-rara.ch/download/pdf/24012184.pdf).
